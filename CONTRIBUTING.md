# Contribuindo

1. Crie uma branch a partir de `main`.
2. Mantenha mudanças pequenas e focadas.
3. Execute formatação, análise e testes antes do commit.
4. Não inclua credenciais, dados pessoais ou conteúdo real de terceiros.
5. Descreva impacto visual e responsivo no pull request.

Commits devem usar mensagens objetivas, preferencialmente no padrão Conventional Commits.
